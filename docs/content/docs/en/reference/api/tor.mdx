description: Tor exits by country, run on this panel server. Each added country
  gets its own Tor on a loopback SOCKS port and becomes the Xray outbound
  "tor-<country>", which routing rules and balancers can name like a tunnel. Tor
  carries TCP only, and the exit relay can read unencrypted traffic. All
  endpoints under /panel/api/tor.

# Pages and where they are

All on the [design canvas](https://claude.ai/artifact/2WxRin6u9HWf1KbcfpR73V). Each laptop artboard has Look tweaks (theme, effects, accent) so every page can be seen in dark and light, at all three effects levels, inside any node.

- **Live prototypes:** Main (dashboard with node switching, live data, Clients route, search, add-client modal, Xray restart stages, Simple/Advanced, effects and theme), Phone dashboard (chip row with +N sheet, quick add), Motion system, Loading and progress.
- **Brand and first touch:** Brand board, Login (laptop, phone), First-run setup (interactive, laptop; phone step), Error page.
- **Subscription page:** phone English and Persian (interactive: copy, QR, app picker, language switch), light, laptop.
- **Panel pages:** Inbounds, Clients (with bulk actions), Groups, Hosts, Activity log, Tunnels (engines as a changing list, flow diagram), Outbounds and routing, Nodes, Edit node (Country, accent picker), Tor and PIA, Xray config, Logs, Settings (Effects, theme, mode, language, future Users and access), Settings › Developer, Modals and empty states, Simple vs Advanced navigation.
- **Light and Persian RTL:** dashboard light, clients light inside Frankfurt, dashboard in Persian, phone dashboard in Persian.
- **Phone:** users, tunnels, more and settings, search across nodes.

**World map (optional idea):** judged and not used. Geography tells an admin little; what matters is which node is reachable through which tunnel. The dashboard uses node summary cards (with chained nodes noted) and the Tunnels page has a flow diagram instead. If a map is wanted later, a stylised dot-grid map is about 20 KB as SVG and can reuse the accent dots.

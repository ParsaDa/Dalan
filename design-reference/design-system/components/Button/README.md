# Button
Primary, secondary (glass), ghost, danger and icon buttons.

- 40 px (sm 32, lg 52; phone primary 52–60), `radius-sm`, 13 px bold. Primary is accent fill with `on-brand` text and a soft accent shadow.
- Press: scale .97 in `d-fast`. Copy and save confirm by swapping the icon and word ("Copied", "Saved") with a spring pop, then return after 1.6–3 s.
- Icon-only buttons always carry an `aria-label`. Touch targets are at least 44 px on phones.

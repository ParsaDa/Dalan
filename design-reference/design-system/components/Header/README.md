# Header
Big greeting, one live status line, then search, Simple/Advanced, Effects, theme, notifications and the account.

- Greeting uses the `display` style; it follows the time of day.
- Status line: a pulsing success dot, the current server, its state in words, and "updated Ns ago" (`aria-live="polite"`). On a problem the state becomes a warning or danger pill.
- Search opens the global search (Ctrl+K on laptop, the search icon on phone). It searches every node.
- Effects: Full / Light / Off segmented control. Theme: one icon button.

# EmptyState
An illustration, one line of title, one or two short sentences, and one action.

- Illustrations are the arch motif: lit saffron doorway for empty, dashed doorway with a danger mark for offline or error, rising arches for first run.
- They use theme tokens, so they work in dark and light without separate files.
- Say what happened and what to do next in plain words. Offline states say that settings are safe.

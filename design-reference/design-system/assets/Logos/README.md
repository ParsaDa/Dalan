# Logos

Three nested arches with a saffron doorway. `dalan-mark-dark.svg` is for dark grounds (cream arches), `dalan-mark-light.svg` for light grounds (ink arches), `dalan-mark-on-saffron.svg` for saffron fills (all ink). In the product the mark is inline SVG so the doorway can take the active node accent. Minimum 16 px; clear space is the doorway width.

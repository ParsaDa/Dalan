# Dalan 0.6.0 design reference (not part of the panel)

Everything here was extracted from Parsa's canvas export `Dalan_0.6.0_design.html` and the
`Dalan_design_system.zip`. This orphan branch exists only to hand the design to whoever builds it.
Never merge it into `main`; check it out into a scratch directory:

    git fetch origin design-reference
    git worktree add /tmp/design-ref origin/design-reference

| Path | What it is |
|---|---|
| `screenshots/*.png` | The 38 artboards as rendered, one per page/variant. The visual truth: the panel must match these. |
| `pages/<Name>.markup.html` | Exact markup of each artboard (`{{…}}` / `sc-if` / `sc-for` are template holes; read them as props and loops). |
| `pages/<Name>.script.js` | The artboard's sample data and behaviour (nav groups, tabs, tunnels, clients, search, restart flow, toasts). |
| `pages/<Name>.css`, `.helm.css` | The shared bundle CSS and each page's own head CSS. |
| `design-system/` | tokens.css/json, README, handoff.md, pages.md, contrast.md, motion.md, components/bundle.css (+ per-component README and preview), assets (flags, logos, icons, illustrations). |
| `starter/design.scoped.css` | bundle.css scoped under `.dl` with namespaced keyframes (generated by `starter/scope-css.py`; untested in the panel). |
| `starter/iconPaths.ts` | The nav/status icon set as inner SVG, copied from Main. |
| `starter/render-boards.mjs` | Playwright script that renders the export and screenshots every artboard (needs the export file). |
| `GAP-NOTES.md` | The earlier gap analysis between the shipped 0.6.0 UI and the design. |

# Dalan 0.6.0 UI Implementation Plan

> For agentic workers: use superpowers:executing-plans. One PR, one commit per task.

**Goal:** Ship the Opus design (Project docs `design/2026-11-20-ui-0.6.0-design-delivered.md`) as the panel UI, in a single PR on `feat/dalan-0.6.0-ui`.

**Architecture:** A token layer (CSS custom properties for dark/light, 12 accents, effects level, motion) drives both plain CSS and the Ant Design 6 theme. Every existing page gets the new look through the theme and a small set of global overrides; the shell (rail, header, node tabs, phone tab bar), dashboard, login, subscription page and Settings are rebuilt to the design. No animation library.

**Tech Stack:** React 19, Ant Design 6 (cssVar mode), Vite, TypeScript, Go (node country + accent fields only).

**Spec:** Design canvas https://claude.ai/artifact/2WxRin6u9HWf1KbcfpR73V, design system https://claude.ai/artifact/6Fu6pnhBE3fABajfh9BXzm (README, motion.md, handoff.md, contrast.md, tokens.json, components/bundle.css).

## Global Constraints
- Repo rules in CLAUDE.md and frontend/CLAUDE.md (comments ≤2 lines, TDD, i18n keys in all 14 locales and referenced in the same commit, endpoints.ts + gen for new routes, migration for DB changes).
- Palette "Saffron and ink"; accent for the Netherlands is Tulip `#F062C8`; custom accent picker refuses hues within 20° of warning or success.
- Effects Full/Light/Off; Light is auto on weak devices, Off is forced by reduce-motion.
- Fonts Manrope + Vazirmatn variable, `font-display: swap`; no icon font; no animation library.
- Persian RTL mirrors layout and motion (`--dir`).

## Scope rulings
- The master-to-node full panel proxy (backend plan §4) is a security-reviewed backend change and is NOT in this PR. Node tabs show per-node dashboard data from heartbeats already on the master.
- Roles / Users and access: not in 0.6.0.
- The first-run wizard is built only if the backend has a first-run state (it has none): decided in Task 9.
